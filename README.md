# GMTK-Game-Jam-2022

GMTK Game Jam 2022向けに48時間で制作したUnityゲームです。

## 成果物

- itch.io: https://nishi10000.itch.io/yakuzadefence

## 概要

短期間のゲームジャムで制作したプロジェクトです。Unityプロジェクト一式とゲーム用アセット、スクリプトを含みます。

## 主なディレクトリ

- `Assets/Scripts/` - ゲームロジック
- `Assets/Scenes/` - Unityシーン
- `Assets/Prefabs/` - プレハブ
- `Assets/Resources/` - リソース
- `Assets/TextMesh Pro/` - TextMesh Pro関連

## 開き方

1. Unity Hubでこのリポジトリを追加
2. Unityでプロジェクトを開く
3. `Assets/Scenes/` 以下のシーンを開いて再生

Unityバージョンは `ProjectSettings/ProjectVersion.txt` を確認してください。

## 備考

ゲームジャム用の短期制作プロジェクトのため、実装やアセット構成はプロトタイプ寄りです。
